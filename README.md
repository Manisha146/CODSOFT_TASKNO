# 🚀 CodSoft Java Development Internship

This repository contains the Java projects developed during my Java Development Internship at CodSoft. These projects helped me gain hands-on experience in Java programming, OOPs, problem-solving, and application development.

## 💻 Projects:-

### 🏦 1. ATM Interface
A Java-based ATM application that simulates basic banking operations and provides a simple console-based banking experience.

**✨ Key Features:**

- Balance Inquiry
- Deposit and Withdrawal
- Transaction Handling
- User Input Validation
- Menu-driven Interface

## **🛠️ Technologies:** Java, OOPs


### 🧠 2. Quiz Application
A Java-based quiz application that allows users to answer multiple-choice questions within a limited time and displays the final score.

**✨ Key Features:**

- Multiple-choice Questions
- Timer-based Quiz
- Answer Validation
- Score Calculation
- Final Result and Percentage
- Time-up Handling

## **🛠️ Technologies:** Java, OOPs


### 🎓 3. Student Course Registration System
A Java-based console application that allows students to view available courses, register for courses, and remove registered courses.

**✨ Key Features:**

- Student Management
- Course Listing
- Course Registration
- Course Removal
- Available Slot Tracking
- Menu-driven Interface

## **🛠️ Technologies:** Java, OOPs
